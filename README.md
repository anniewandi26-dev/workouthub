## 双击打开（桌面 HTML，与公网同步）

运行同步后，桌面会生成：

1. **`WorkoutHub.html`** — 双击即可打开公网同步网页  
2. **`WorkoutHub-html/`** — 完整静态站点副本（可用本地服务器预览）

```bash
npm run sync:html
```

每次改完代码：`npm run sync:html` → 提交推送 → 公网与桌面 HTML 一起更新。
